Nhạc nền cho từng map (tùy chọn)

Đặt file mp3 vào thư mục này, đặt tên theo mã map:

  saigon.mp3   -> Dinh Độc Lập
  meadow.mp3   -> Đồng cỏ
  desert.mp3   -> Sa mạc
  snow.mp3     -> Băng tuyết
  beach.mp3    -> Bãi biển
  farm.mp3     -> Nông trại

Map nào có file thì phát file đó (lặp lại) từ lúc đếm ngược tới lúc trao giải;
không có file thì dùng nhạc 8-bit có sẵn. Không cần khởi động lại server.
Chỉ dùng nhạc bạn có quyền sử dụng (nguồn miễn phí / bản quyền cho phép).
